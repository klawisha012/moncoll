# Юнит-тестирование (Unit Tests) WAF

В этой директории находятся юнит-тесты для Web Application Firewall (WAF). Эти тесты предназначены для быстрой проверки изолированных модулей бизнес-логики без обращения к внешним ресурсам.

---

## Особенности юнит-тестов

1. **Максимальная скорость**: Выполняются за доли секунды, так как работают полностью в оперативной памяти.
2. **Полная изоляция**: Не требуют запущенных баз данных (PostgreSQL, ClickHouse), Docker-контейнеров, Redis или внешних API.
3. **Мокирование (Mocking)**: Все внешние зависимости и системные вызовы (например, отправка писем по SMTP, DNS-запросы, проверка капчи, генерация сертификатов) полностью изолированы с помощью библиотеки `unittest.mock` и фикстур `pytest`.
4. **Автоматическая разметка**: Благодаря кастомному хуку в `tests/conftest.py`, все файлы в этой папке автоматически получают маркер `@pytest.mark.unit`.

## Подготовка окружения

Перед запуском убедитесь, что в вашем виртуальном окружении установлены все тестовые зависимости:

```bash
# Через uv (рекомендуется)
uv pip install -r tests/requirements.txt

# Или через стандартный pip
pip install -r tests/requirements.txt
```

## Запуск юнит-тестов

### 1. Запуск всех юнит-тестов

Вы можете запустить тесты по маркеру `unit` или указав путь к папке:

```bash
# Запуск по маркеру
pytest -m unit

# Запуск по пути (с подробным выводом)
pytest tests/unit/ -v
```

### 2. Запуск конкретного тестового файла

Для проверки отдельного модуля запустите pytest с указанием пути к файлу:

```bash
pytest tests/unit/backend/test_captcha.py -v
```

### 3. Запуск конкретного теста внутри файла

Используйте флаг `-k` для фильтрации по имени тестовой функции:

```bash
pytest tests/unit/backend/test_captcha.py -k "test_verify_captcha" -v
```

## Полезные флаги Pytest для разработки

* `--lf` (`--last-failed`): Перезапустить только те тесты, которые упали во время предыдущего запуска.
* `-x` (`--exitfirst`): Остановить выполнение всего набора тестов при первой же ошибке.
* `-s`: Не перехватывать вывод в stdout (вы сможете видеть логи и вызовы `print` прямо в консоли во время выполнения).
* `--tb=short`: Использовать сокращенный формат вывода ошибок (упрощает чтение стектрейсов).
