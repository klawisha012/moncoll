A · Inset Modal

Default direction per spec §7.1. Classic dialog pattern, dimmed list visible behind.

  • Lowest friction to implement (one component)
  • Mobile: becomes full-screen sheet (§7.4)
  • Closest to existing app patterns
  • Risk: feels conventional, doesn't differentiate

B · Editorial Poster

Full-pane wizard with massive numeral anchor. Brand-first hierarchy, magazine-spread feel.

  • Strongest brand impression in onboarding
  • Plenty of breathing room — Constructivist showcase
  • Resume flow still works (returns to list, badge says "Resume setup")
  • Risk: full-pane means user loses context of list during setup

C · Terminal / Control-Panel

Mono-typed wizard styled as a command-line session. Underlines WAF's technical nature.

  • On-brand for sysadmin/infra audience
  • Compact — fits in a smaller modal than A
  • Animated red caret keeps it alive
  • Risk: alienates non-technical users; mono fonts harder to scan
