h5bp · Mode 1 example

If you see this page, the WAF deployed the h5bp nginx.conf server block and is serving this static index.html from the per-connection site directory.

This example uses the upstream h5bp/server-configs-nginx modular partials: security headers, safe file-access defaults, compression, and long-cache headers — all wired in via include h5bp/basic.conf;.

Verify it's wired up

curl -H 'Host: h5bp.test' http://localhost/probe
# expected: mode1-h5bp-ok

The /probe endpoint short-circuits to a 200, bypassing ModSecurity (the WAF auto-injects modsecurity off; on health-style locations).

What you're seeing

  • Mode: nginx_config
  • nginx_config_path: /app/site-templates/examples/mode1_h5bp/nginx.conf
  • Static root (auto-derived): the directory containing nginx.conf, copied into the connection's site dir, minus *.conf files.
